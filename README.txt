Your site is ready for GitHub Pages.

1. Unzip this file.
2. Create a repository on GitHub (a public one is fine).
3. Upload everything from the unzipped folder (index.html, the assets folder and .nojekyll) to the repository.
   On github.com: Add file > Upload files, then drag the contents in.
   GitHub's website accepts up to 25 MB per file in the browser and 100 MB per file through git or GitHub Desktop.
4. In the repository open Settings > Pages, set Source to "Deploy from a branch", pick the main branch and the / (root) folder, and Save.
5. After a minute or two the site is live at https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

To update the site later, export again and upload the new files over the old ones.
